🛡️ Via Safe

📌 Sobre o Projeto

O Via Safe é uma aplicação desenvolvida como projeto acadêmico com o objetivo de promover maior segurança, monitoramento ou prevenção de incidentes em vias públicas e trajetos do dia a dia.

A plataforma busca auxiliar usuários na identificação de rotas seguras, reporte de ocorrências em tempo real e visualização de pontos de atenção, combinando tecnologia e conscientização para melhorar a mobilidade urbana.

🛠️ Tecnologias Utilizadas

Ajuste a lista abaixo conforme a stack real utilizada no projeto.

Frontend: HTML5, CSS3, JavaScript / React / React Native

Backend: Node.js / Python

Banco de Dados: PostgreSQL / MongoDB / Firebase

Mapeamento & APIs: Google Maps API / Leaflet

Controle de Versão: Git & GitHub

⚙️ Pré-requisitos

Antes de iniciar, garanta que possui as seguintes ferramentas instaladas em seu ambiente:

Git

Node.js (versão LTS recomendada)

Um navegador moderno ou emulador (caso seja um app mobile)

🚀 Como Executar o Projeto

Siga os passos abaixo para rodar o projeto localmente:

1. Clonar o repositório

git clone https://github.com/nicolasswe/Via_Safe.git
cd Via_Safe


2. Instalar as dependências

Se o projeto utilizar Node.js / npm:

npm install


(ou yarn install, caso utilizem Yarn)

3. Configurar Variáveis de Ambiente (se necessário)

Crie um arquivo .env na raiz do projeto baseado no .env.example e adicione as chaves necessárias (ex: chaves de API do Google Maps ou credenciais de banco de dados).

4. Executar a aplicação

Para projetos Web (React/Vite/HTML):

npm start
# ou
npm run dev


Para projetos Mobile (React Native / Expo):

npx expo start


Abra o navegador em http://localhost:3000 (ou na porta indicada no terminal) para visualizar a aplicação.
